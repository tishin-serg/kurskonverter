# Регион Bybit P2P

Проблема: API возвращает объявления с `tradingPreferenceSet.hasNationalLimit`
и `nationalLimit`, даже когда они не подходят стране KYC пользователя. Раньше
адаптер терял эти поля, и недоступная дешёвая заявка могла выигрывать расчёт.

Теперь объявления сохраняют список запрещённых стран KYC. Настройка пользователя
«Страна KYC Bybit» применяется при подборе покупки USDT за RUB и продажи USDT
за USD на TBC. Для Российской Федерации используется `RUS`.
Если страна пользователя присутствует в `nationalLimit`, объявление исключается.
Страна банка, IP сервера и язык Telegram не используются для определения KYC.

Если страна пользователя не задана, объявления с региональными ограничениями
исключаются. Если API не вернул корректный флаг ограничений или список стран
при включённом флаге, объявление исключается на этапе нормализации.
`blocked` должен быть явно `N`. Отключённое ограничение может содержать старый
список стран: при `hasNationalLimit=0` этот список не применяется.

Источник структуры и кодов:
https://bybit-exchange.github.io/docs/p2p/ad/post-new-ad
https://bybit-exchange.github.io/docs/p2p/ad/online-ad-list
Поля проверены в живом ответе API 2026-09-11.

Это проверка региональных условий объявления, а не полная проверка возможности
создать ордер. Требования к сроку регистрации, числу сделок покупателя,
дополнительной проверке, реквизитам и свободный текст продавца здесь не проверяются.
Подтверждение доступности сделки остаётся на Bybit. Исторические расчёты не
пересчитываются: кнопка «Обновить» применяет текущие настройки и свежие объявления.

Миграция 005 добавляет отдельную страну каждому пользователю. По умолчанию она
не задана: при обновлении нельзя назначать всем пользователям страну владельца.
После деплоя для аккаунта владельца выбрать «Настройки → Страна KYC Bybit → Россия».

Проверки: смешанная выдача валидных и некорректных объявлений, строковые/числовые
флаги, отсутствие региона, сравнение цен с недоступной более дешёвой заявкой,
регион на обеих P2P-стадиях, изоляция пользователей и сохранение после перезапуска.
